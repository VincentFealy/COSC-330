# COSC-330: OO Design Patterns and GUI/Event-Driven Programming

This repository contains labs and programming projects completed for **COSC-330: OO Design Patterns and GUI/Event-Driven Programming** at **Salisbury University**.

## Overview

This course focused on object-oriented software design, design patterns, graphical user interface development, and event-driven programming. Coursework included programming exercises and projects designed to apply object-oriented design principles to software development.
